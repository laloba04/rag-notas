**Pro Git es NC (no comercial):** vale para un proyecto de portfolio o de aprendizaje. Si algún día el proyecto pasa a ser un producto comercial, hay que sustituir esos documentos.

`extra/21-notas-migracion-TRAMPA.md` no es documentación real: es un documento sintético creado para la prueba de prompt injection.
